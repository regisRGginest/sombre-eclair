SITE SOMBRE ÉCLAIR

1. Créez un compte GitHub.
2. Créez un nouveau dépôt nommé sombre-eclair.
3. Téléversez tout le contenu de ce dossier.
4. Dans Settings > Pages, choisissez Deploy from a branch, puis main / root.
5. Votre lien apparaîtra après quelques minutes.

Avant publication : complétez les mentions légales (SIRET, adresse professionnelle).
